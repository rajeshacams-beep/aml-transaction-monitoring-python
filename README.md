# 🛡️ AML Transaction Monitoring – Python Case Study

## 📖 Overview
This project demonstrates how a simple Python model can detect anomalies in declared vs. actual cash deposits.  
A customer declared **100K AED monthly deposits**, but the model found **> 500K AED** in two months — triggering a **Financial Crime Risk Tool alert**.

## ⚙️ Skills Demonstrated
- Python programming (loops, conditions, `break`)
- AML transaction monitoring logic
- Data visualization using Matplotlib
- Compliance risk detection workflow
